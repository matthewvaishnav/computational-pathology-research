# Paired-acquisition provenance manifest

This package freezes a deterministic, read-only provenance inventory for the
426 NPZ archives used by the scanner-invariant residual feasibility audit. It
records observed metadata, lineage expectations, proposed canonical values, and
the limits of family-level generator/run evidence before any new training or
crossed-preparation study is designed.

The package is an evidence ledger, not a scientific result. A metadata-lineage
conflict does not determine the scientific validity of an archive, experiment,
model, or reported metric.

## Outputs

- `provenance_manifest.csv`: one deterministically identified row per archive.
- `provenance_conflicts.csv`: one row per metadata-lineage conflict or other
  unresolved provenance issue.
- `provenance_validation_report.md`: inventory, conflict, resolution, evidence,
  hashing, and limitation summaries.

The supporting specifications are:

- `manifest_spec.md`
- `resolution_rules.md`
- `required_evidence.md`

## Commands

Generate the three deterministic outputs:

```powershell
python benchmarks\paired_acquisition_provenance_manifest\build_provenance_manifest.py
```

Compare generated bytes with the checked package outputs without writing:

```powershell
python benchmarks\paired_acquisition_provenance_manifest\build_provenance_manifest.py --check
```

Emit a stable JSON validation summary without writing:

```powershell
python benchmarks\paired_acquisition_provenance_manifest\build_provenance_manifest.py --format json
```

Run temporary fail-closed and bounded-behavior tests:

```powershell
python benchmarks\paired_acquisition_provenance_manifest\build_provenance_manifest.py --self-test
```

Default execution may replace only the two CSVs and the validation report in
this directory. Check, JSON, and self-test modes do not write repository files.
Temporary self-test fixtures are deleted before the command returns.

## Current bounded result

- 426 archives are accessible: 201 canine SCC and 225 SCORPION.
- All 426 raw content hashes are unique.
- 200 source-label conflicts and 150 explicitly gated backbone/model-label
  conflicts are reproduced with no overlap.
- The 350 conflict rows remain unresolved. Their canonical fields contain
  medium-confidence proposed lineage interpretations, not adjudicated changes.
- Reachable generator/result history supplies family-level context but does not
  bind the present archive bytes to exact historical invocations.
- No row qualifies as `corrected`; 50 rows are currently metadata-lineage
  consistent and 26 are legacy-optional.
- Of 226 archives lacking optional explicit backbone metadata, 200 also have a
  source-label conflict and are unresolved; the remaining 26 have no
  contradiction and are legacy-optional.
- All 426 rows still lack historical output-hash binding.

Dedicated `observed_*` columns preserve the archive metadata verbatim alongside
the proposed canonical values. The proposals do not rewrite source NPZs, alter
result files, expand prior claims, establish historical byte identity, or
identify a causal or biological provenance for representation signal.

All 426 NPZs are locally accessible in the audited workspace, but none is
Git-tracked by this repository. This package does not establish public artifact
availability. Deterministic checking requires all three of:

- all 426 source archives;
- all reachable Git commit:path references recorded by the manifest; and
- the separately supplied local-untracked file
  `results/external_multiscanner_caninescc/features/fold_0_dinov2_base.summary.json`.

That adjacent summary is local-untracked context and present-workspace context
only. It is untracked and non-adjudicating; its current-state availability does
not prove historical origin, which remains unverified, and archive-specific
adjudication is absent. Full deterministic checking fails closed if this local
context file is absent.
