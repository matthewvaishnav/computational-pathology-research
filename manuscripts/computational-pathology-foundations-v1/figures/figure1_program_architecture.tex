\begin{equation}
\begin{aligned}
\text{Paired acquisition:}\quad
&\{h_{r,s}\}_{s\in\mathcal S_r}
 \xrightarrow{\ \mathcal F_{\mathrm{pair}}\ }
 (b_{r,s},a_{r,s}),\\
\text{Whole slide:}\quad
&\{(z_{k,j},p_{k,j})\}_{j\in\mathcal B_k}
 \xrightarrow{\ \mathcal A_{\mathrm{slide}}\ }
 \widehat y_k,\\
\text{Multi-site:}\quad
&\{(\Delta\theta_i^{(t)},w_i^{(t)})\}_{i\in\mathcal I_t}
 \xrightarrow{\ \mathcal A_{\mathrm{site}}\ }
 \theta^{(t+1)}.
\end{aligned}
\label{eq:program}
\end{equation}

\noindent These mappings describe three evaluated decision levels. The paired representation experiment uses frozen visual features $h_{r,s}=E_\omega(x_{r,s})$; slide aggregation uses a bag of patch representations $z_{k,j}$ with optional positions $p_{k,j}$; institutional aggregation combines client updates using weights $w_i^{(t)}$. The reported results use different datasets, splits and comparators. In particular, no experiment in this manuscript estimates a jointly trained mapping from PA-NF features through slide prediction to federated updates.
