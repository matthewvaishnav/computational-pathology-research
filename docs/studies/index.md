## Linking policy

Public method names use logical titles such as **Paired-Acquisition Neural Factorization**. Repository URLs may temporarily retain legacy slugs so existing GitHub links, scripts, result paths, and build references continue to work.

Do not link to GitHub Pages PDFs until those pages are actually published. The repository link is the stable public entry point for each study package.
