## Linking policy

The main PDF should state the program-level claim and link outward for study-specific details. Child study PDFs should carry the frozen protocol, exact result tables, and reproduction instructions for one bounded claim.

This avoids turning the main paper into a dumping ground while preserving a clear public chain from broad claim to exact evidence.
