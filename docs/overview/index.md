# Overview

This project is a computational pathology research platform combining:

- whole-slide image and patch-level pathology modeling
- multiple-instance learning architectures
- custom TransnnMIL v2.0 model development
- PathologyFL federated learning infrastructure
- FAIR-WEIGHTS-H institutional weighting research
- PCam and Camelyon validation workflows
- engineering infrastructure for testing, security, and deployment

## Current status

The platform has working research scaffolds, passing focused tests, PCam patch-level smoke validation, and MkDocs documentation. Real multi-center Camelyon17 WSI validation remains future work.
