# Repository Overview

This repository contains computational pathology research code, federated learning infrastructure, FAIR-WEIGHTS-H weighting experiments, validation scripts, and documentation.

## Main areas

- `src/` — implementation code
- `tests/` — unit and integration tests
- `scripts/` — experiment and smoke-test entrypoints
- `docs/` — canonical MkDocs documentation
- `website/` — legacy Docusaurus site during migration
