# Historical roadmap: superseded

This April 2026 roadmap is obsolete and must not be used as the current project
status.

The previous version incorrectly described the repository as synthetic-only.
Current benchmark work uses public pathology datasets derived from real human
tissue, including PCam, PANDA, and CAMELYON17/WILDS. Generated fixtures are limited
to isolated software tests and are not the source of reported benchmark results.
