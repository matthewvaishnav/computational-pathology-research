# Scientific audit remediation — 2026-07-25

## Purpose

This ledger records which scientific problems were corrected in code, which
historical claims were withdrawn, and which experiments must be rerun before new
numbers can be promoted.

A code correction does not retroactively validate an artifact generated by old
code or an old analysis protocol.

## Corrected in this branch

### TransnnMIL

- Replaced the one-query/one-key fusion path with self-attention over explicit
  branch tokens.
- Both TransMIL and nnMIL branch representations can now affect the fused output.
- Moved the topology projection into `__init__` as a registered trainable module.
- Retained the old gate parameter only for checkpoint/API compatibility and
  stopped interpreting it as branch importance.
- Added tests requiring output sensitivity and gradient flow to both branches.
- Preserved concat, gate, and learned branch-attention implementations as
  controlled fusion alternatives.

### Canine biological-label preservation

- Added an intermediate v2 runner with fit-only standardization, fit-pool
  neighbours, same-region and same-sample exclusions, and fail-closed metadata
  checks.
- Added the current fixed-estimand runner:
  `run_biological_label_preservation_fixed_estimand.py`.
- The fixed-estimand runner selects one category set supported by at least the
  configured number of fit and test biological samples in every fold.
- It uses the same category set for all five folds.
- It includes the strongest historical oldstyle centroid/QR keep and removed
  branches alongside paired, shuffled, PCA, and standardized-centroid controls.
- It averages optimization seeds within fold and reports five-fold means and
  ranges without patch-independent p-values.
- The historical category report is explicitly superseded.

### SCORPION analysis and controls

- Added fold-aware two-stage fold/slide bootstrap inference.
- Withdrew slide-level sign-flip p-values as exact independent-unit evidence.
- Added frozen capacity-matched objective ablations, including a two-branch model
  with no scanner objectives and removal of each principal separation term.
- Added explicit documentation that near-saturated same-region retrieval and
  cosine agreement are representation metrics, not proof of retained biology.

### PCam

- Removed the unsupported cross-paper leaderboard and significance claims.
- Removed claims about diagnoses saved, lives saved, clinical benefit, clinical
  readiness, workflow burden, or deployment.
- Reframed threshold values as retrospective test-set operating-point
  illustrations requiring validation-selected confirmation.

### Cross-experiment reporting and manuscripts

- Withdrew the unified scoreboard as a ranking device.
- Withdrew the old baseline report's claims of tissue damage and best trade-off.
- Replaced the stale paired-acquisition manuscript draft with an audit-hold and
  reconstruction plan.
- Replaced the numerical claim ledger with an audit-aware active claim ledger.
- Updated the root README and `CLAIM_BOUNDARY.md` so withdrawn evidence cannot be
  presented as current.
- Put the public paper site on scientific-audit hold. The LaTeX source is still
  built as an internal review artifact, but the stale PDF will no longer be
  republished as an authoritative public paper.

## Remaining limitations not solvable by a code patch

- SCORPION has no biological-category labels.
- Canine SCC remains the only labeled multi-scanner category benchmark.
- A second labeled multi-scanner dataset is needed for category-level external
  confirmation.
- Independent human-tissue external validation remains necessary.
- PANDA patient-disjoint evaluation requires trustworthy patient mapping.
- CAMELYON17 provides one held-out test institution for the current centralized
  center-weighting case study.
- Clinical, diagnostic, patient-outcome, and deployment claims remain forbidden.

## Current defensible center of gravity

> Under the tested paired-acquisition protocols, the learned tissue-oriented
> branch contains substantially less linearly recoverable scanner identity,
> while an explicit acquisition branch retains scanner information and
> same-region tissue identity is largely preserved.

This is evidence of partial structured separation under tested conditions. It is
not proof of pure biological factors, complete independence, universal scanner
invariance, clinical utility, or diagnostic improvement.
